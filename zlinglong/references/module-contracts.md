# 四个模块的调用契约（骨架，未核验）

> 通用前置：任何模块开始前执行 `python scripts/deps_check.py`。

## 模块 1 · 计算与结果核对

- 输入：题面 + 待核对数值（可选）。
- 必需调用：`scripts/chembox.py` 对应子命令；数据一律取自 `data/` 或 `vendor/chemlib/resources/`。
- 输出：数值结果、单位与有效数字、所用子命令与函数、出处附录。
- 失败：缺依赖 → FATAL；缺数据 → 「知识库未收录」。

## 模块 2 · 解题

- 输入：完整题面。
- 必需调用：先 `rg -n` 命中知识条目，再执行一次或多次 `chembox` 计算。
- 输出：分步解答，每一步标注其知识条目 id；数值全部来自脚本输出。
- 失败：命中 D-1 推迟能力时，该步输出「知识库未收录（能力推迟）」，不得自算。

## 模块 3 · 过程分析

- 输入：题面或反应流程。
- 必需调用：知识条目检索；涉及数值时调用 `chembox`。
- 输出：机理/流程的分步说明，每步附条目 id。
- 失败：同模块 2。

## 模块 4 · 题目拓展

- 输入：源题。
- 必需调用：源题已命中的知识条目 id 集合。
- 输出：2–3 道变式（基础/提升/综合），含答案与解析，附录引用源题条目 id（当前为占位态，Z-G 决定保留占位）。
- 失败：无法定位源题条目时拒绝生成。
