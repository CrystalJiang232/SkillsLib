# 出处附录契约（骨架，未核验）

## 格式

```text
—— 出处附录（内部引用）——
- <file>:<line>   (id: <条目 id>)   <该条目的结论要点>
- scripts/<模块>.py:<line>   <函数名>()
- 引擎: vendor/chemlib 2.2.4 (sha256 见 references/dependencies.md)
- 未核验项: <列出本次涉及的「未核验」条目；无则写「无」>
- 未查知识库: 无 | <若确无知识文件被使用，必须显式声明>
```

## 坐标来源规则

1. 附录坐标只能来自工具输出：`rg -n` 的 `file:line` 或脚本的 JSON `sources` 字段，原样复制。
2. 不得凭记忆书写行号，也不得用「大约在这一段」之类的近似表述。
3. 复核方式：对同一 id 记号重跑 `rg -n "<id>"`，坐标不一致即以复核结果为准并更正。

## 失败分支

| 情形 | 附录写法 |
|------|----------|
| 命中推迟能力（D-1） | `- 推迟项: D-1 离子/电荷相关，本次未计算` |
| 数据表命中占位记录 | `- 未收录: <表名> 为骨架占位` |
| 计算未执行 | 明确写出「本次未执行计算」，不得省略 |
